# Theme upgrade projects

Per-project intake files for `typo3-qa-clickup`.

- Template: [`.cursor/skills/typo3-qa-clickup/PROJECT-INTAKE.md`](../.cursor/skills/typo3-qa-clickup/PROJECT-INTAKE.md)
- Save as `{project-slug}-intake.md` here.
- Omit passwords and ClickUp tokens. Mark those as `session only`.

Examples of slug names: `acme-v14`, `client-theme-upgrade`, `ns_theme_xyz-staging`.

After a filled intake exists, the agent confirms the summary (no secrets) and runs FE / BE / CE per [`WORKFLOW.md`](../WORKFLOW.md).
